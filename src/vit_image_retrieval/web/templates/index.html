About the System

Vision Transformer (ViT)

Uses pre-trained ViT-B/16 model from torchvision for robust feature extraction. The model was trained on ImageNet and provides excellent representation of visual content.

FAISS Indexing

Implements FAISS IVF (Inverted File) indexing for efficient similarity search. Supports both CPU and GPU acceleration for fast retrieval from large image collections.

Features
  • Multiple image format support (PNG, JPG, JPEG, WebP)
  • GPU acceleration for faster processing
  • Web-based interface accessible from any browser
  • Progress tracking for batch operations
